This policy describes the personal Google API configuration operated by chrisWop, identified as gcalcli on its OAuth branding. It covers personal calendar tools and rclone Google Drive backups. It is not a service offered to the public.

Google data accessed and why

  • Google Calendar: event and calendar information needed to view, plan, create, or update events as authorized by the owner.
  • Google Drive: file contents and metadata needed for authorized backup uploads, listings, downloads, verification, and restore operations.
  • Authorization information: OAuth tokens and related configuration needed to maintain the owner's authorized connections.

The permissions actually granted are shown on Google's consent screen. This website itself does not connect to Google APIs or collect Google account data.

Use and sharing

Google data is used to provide the owner's requested calendar and backup functionality. Data may be processed by Google and the owner's configured automation or AI service providers when needed for those requested functions. Such processing is distinct from this static website and is subject to the applicable provider's terms and privacy policy.

This personal configuration does not sell Google user data or use it for advertising. Its use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

OAuth credentials and private operational data are kept in the owner's private systems, not in this public website or its repository. Duplicati backup archives are encrypted before upload and stored in the owner's Google Drive. Calendar data remains in Google Calendar, with any local records or processing governed by the owner's configured tools.

Retention, deletion, and revocation

Backup history is retained according to the configured backup-retention settings. Local credentials and records are retained while needed for the owner's setup. The owner can delete local records and backup archives using the relevant tools and can revoke OAuth access through Google Account connections.

Revoking access prevents future authorized API access; it does not automatically delete previously stored records or backups. Deleting a calendar event does not automatically remove any separate historical copy.

Website hosting

These static pages have no sign-in form, analytics scripts, advertising, or application cookies. GitHub Pages hosts this website and may process visitor information such as IP addresses for security and service operation under the GitHub privacy statement.

Contact and changes

Contact the operator through the chrisWop GitHub profile. Do not send tokens, passwords, backup files, or private calendar details through public channels. This policy will be updated if the configuration's data practices change.
