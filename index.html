gcalcli
Personal Google tools.

A private, owner-operated configuration for managing Google Calendar and using rclone with Google Drive for personal backups.

This is an informational website for the owner's Google OAuth configuration—not a public app or a sign-in portal. It does not provide access to calendars, files, or backups.

Calendar management

Calendar tools such as gcalcli and authorized personal automation help the owner view and manage calendar events. Access is granted through Google's consent screen and is used for the calendar operations the owner authorizes.

Google Drive backups

rclone provides authorized Google Drive file access for storing and retrieving personal backup archives. Duplicati encrypts backup archives before uploading them to Google Drive.

Permissions and control

Only the owner's Google accounts are intended to use this configuration. Permissions are granted through Google; this website never asks for a Google password, authorization code, or token. The owner can revoke access from their Google Account.
